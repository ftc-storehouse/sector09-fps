# SECTOR-09 : CRYO BREACH

高细节单关卡战术第一人称射击游戏（WebGL2 / Three.js + TypeScript + Vite），纯代码程序化生成高精度双色调模块化步枪、2K PBR 法线/粗糙度材质、实时积水镜面反射与地下空间脉冲混响音效。

## 核心特性

- **次世代渲染管线**：Half-Float HDR + 4x MSAA + ACES Filmic 色调映射 + Unreal Bloom + CAS 自适应锐化 + 动态边缘色差与胶片颗粒。
- **实时积水镜面反射**：环氧混凝土地面结合实时平面反射与积水遮罩，踩过水洼自动触发涉水脚步声。
- **高精度模块化步枪 (MCX-Spear)**：
  - 28 齿独立皮卡汀尼导轨、随射击往复运动与空仓挂机的镀铬枪机、透明余弹观察窗弹匣。
  - 全息视差准星（右键开镜光学中心精准对齐）+ 枪侧实时 OLED 弹药/枪管温度屏。
  - 连射枪管过热发红与枪口热烟、`[V]` 快拆钛合金消音器、`[B]` 快慢机单发/全自动切换、`[T]` 动态阴影战术强光手电与 PEQ-15 绿激光。
- **战术身法与物理破坏**：
  - `[Q] / [E]` 防穿模掩体探头（联动侧倾战术据枪）、`[Shift + C]` 冲刺滑铲、`[F]` 武器检视、`[R]` 战术换弹（30+1）/空仓拍击挂机换弹。
  - 5.56mm 黄铜弹壳物理弹跳落地；可击碎吊灯（动态熄灭阴影）、防弹玻璃、高压蒸汽管、灭火器与二次引爆低温燃料罐。
- **分部位装甲 AI**：突击合成体、机动无人机与重装指挥官三波次递进遭遇战，支持爆头碎镜暴击与可击碎脱落陶瓷胸甲。

## 快速运行

```bash
npm install
npm run dev
```

构建生产版本：

```bash
npm run build
```
